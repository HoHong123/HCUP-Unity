# HCUP 1.1.1 릴리즈 노트

---

## 개요

HWindows 패키지를 신설한 릴리즈입니다. GraphView 기반 NodeWindow 에디터 서브모듈이 포함됩니다. Unity 2022.3 LTS ~ 6000.3.11f1 호환을 확인했습니다.

## 1.1.1에서 변경된 점

---

- `HWindows` UPM 패키지 신설. 메인 패키지가 4개에서 5개로 증가했습니다.
- NodeWindow 서브모듈 도입 — `NodeCatalogSO`(그래프 컨테이너 ScriptableObject) + 3 노드 타입(Simple / Hub / Catalog) + Undo/Redo + Cut/Paste(JSON 클립보드) + Search + 메뉴바([View▾][Edit▾]).
- NodeWindow Runtime 어셈블리(`HCUP.HWindows.NodeWindow`) — 노드 데이터 계약(ScriptableObject) 포함.
- NodeWindow Editor 어셈블리(`HCUP.HWindows.NodeWindow.Editor`) — GraphView 어댑터, Authoring 게이트, Settings 인프라 포함.
- Unity 2022.3 LTS ~ 6000.3.11f1 호환 확인. C# 9 상한 준수. Unity 6000+ 전용 API는 `#if UNITY_6000_0_OR_NEWER` 분기 적용.

## 패키지 / 어셈블리 구성

---

- 메인 UPM 패키지 5개: HUtil, HUI, HGame, HAudio, HWindows
- 분리 어셈블리 5개: HCollection, HCore, HData, HDiagnosis, HInspector

## 주의사항

---

- `NodeCatalogSO`를 Unity MCP의 `assets-modify`로 수정하지 않습니다. 명시하지 않은 필드가 기본값(0)으로 리셋됩니다. YAML 직접 수정 + `assets-refresh` 조합을 사용합니다.
- `UnityEditor.Experimental.GraphView`에 의존합니다. Experimental 태그는 2022.3 ~ 6000.3 범위에서 breaking change가 없음을 확인했으나, 이후 Unity 버전에서 API 변경 가능성이 있습니다.
